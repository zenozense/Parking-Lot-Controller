Smart Parking System

ระบบแสดงจำนวนช่องจอดรถว่างหน้าคณะ IT เพื่อให้ผู้ขับรถรู้สถานะที่จอดรถก่อนขับเข้าไป

ลองกดปุ่มทางขวา (หรือด้านล่างบนมือถือ) เพื่อดูว่าระบบนับรถและแสดงผลอย่างไร

จำลองการทำงาน ใช้ตัวอย่าง 12 ช่องจอด

ปิดไม้กั้น

ว่าง 7 ช่อง

12−5=7

ช่องจอดทั้งหมด − รถที่จอดอยู่ = ช่องว่าง

ปุ่มแทนสัญญาณจากเซนเซอร์ HC-SR04 ที่ตรวจจับรถเข้าและออก จำนวนช่องในตัวอย่างนี้เป็นค่าสมมติ

ปัญหา

ถนนที่จอดรถคณะ IT แคบ ทำให้สัญจรลำบากเมื่อมีรถหนาแน่น เมื่อที่จอดรถเต็ม ผู้ขับรถต้องเข้าไปวนหาที่จอดในพื้นที่แคบ ทำให้เกิดรถติดและเสี่ยงต่ออุบัติเหตุ

จุดประสงค์ของโปรเจกต์

  • แสดงจำนวนช่องจอดรถที่ว่างให้ผู้ขับรถทราบก่อนเข้าพื้นที่
  • ลดการวนหาที่จอดรถในถนนแคบ
  • ลดความหนาแน่นของการจราจรหน้าคณะ

ผู้ที่ได้รับประโยชน์

ผู้ที่มาจอดรถที่คณะ IT

รายละเอียดโปรเจกต์

Input

  • จำนวนช่องจอดรถทั้งหมด
  • จำนวนรถที่เข้ามาจอด

Output

  • LED, จอ แสดงจำนวนช่องจอดรถที่ว่าง

หลักการทำงาน

  1. ระบบกำหนดจำนวนช่องจอดทั้งหมดไว้ล่วงหน้า
  2. เซนเซอร์ตรวจจับรถที่เข้า/ออก และนับจำนวนรถที่จอดอยู่
  3. ระบบคำนวณจำนวนช่องว่าง
    ช่องว่าง = ช่องจอดทั้งหมด − จำนวนรถที่จอดอยู่
  4. แสดงผลด้วย LED ให้ผู้ขับรถเห็น (เมื่อเต็มจะแสดงสถานะเต็ม)

ความน่าสนใจและแปลกใหม่

  • ต้นทุนต่ำ
  • แก้ปัญหาจริงในพื้นที่จริง

ประโยชน์

ผู้ขับรถ
ประหยัดเวลา ไม่ต้องวนหาที่
การจราจรในพื้นที่
ลดรถติดและความเสี่ยงบนถนนแคบ
สิ่งแวดล้อม
รถวนน้อยลง ใช้น้ำมันและปล่อยมลพิษน้อยลง

อุปกรณ์

  • Arduino Unoบอร์ดควบคุมระบบ
  • HC-SR04เซนเซอร์อัลตราโซนิก ตรวจจับรถเข้า/ออก
  • LEDแสดงสถานะว่างหรือเต็ม
  • 1602 LCD I2Cแสดงจำนวนช่องจอดที่ว่าง
  • Servo SG90ไม้กั้น
  • Breadboard, สายจัมเปอร์, ตัวต้านทาน 220Ωต่อวงจร

ไลบรารี

  • Servo.hควบคุมไม้กั้น
  • LiquidCrystal_I2Cควบคุมจอ LCD
